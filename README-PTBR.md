# Win7Keu — site independente (versão inicial)

Esta é uma base original de site/PWA com uma área de trabalho inspirada no estilo clássico do Windows 7.

## O que já funciona
- Área de trabalho adaptada para celular e computador.
- Menu Iniciar.
- Janelas de Computador, Meus arquivos, Media Player e Sobre.
- Relógio na barra de tarefas.
- Seleção e reprodução de um arquivo de áudio local.
- Estrutura PWA com manifesto e service worker para permitir instalação/uso offline básico após a primeira visita.

## O que ainda não foi conectado
- Cadastro e login de visitantes.
- Perfil público do administrador e permissões.
- Banco de dados e armazenamento Supabase.
- Biblioteca pública, compartilhamento e moderação de arquivos.
- Central de notificações administrativa.
- Atalhos externos e recursos adicionais solicitados.
- Empacotamento Android/APK.

## Como testar
Abra `index.html` em um navegador para uma prévia local. Para instalar como PWA, publique os arquivos em uma hospedagem HTTPS. O service worker funciona em contexto seguro (HTTPS ou localhost).

Esta base não contém código, anúncios ou desbloqueios Premium de aplicativos de terceiros.
